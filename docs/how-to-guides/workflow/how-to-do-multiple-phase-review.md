# How to do multiple phase review

If the same reviewers review both rounds, we recommend this workflow:

1. Run the first round of review as usual, with the **Official Review** step.
2. Post decisions only for the submissions you are rejecting, and run the **Create Rejected Submission Release** step for them. See [How to make papers public after decisions are made](how-to-make-papers-public-after-decisions-are-made.md).
3. Run the second round of review as a review revision, created with the CustomStage. See [How to enable the Review Revision Stage](how-to-enable-the-review-revision-stage.md).
4. Post remaining decisions and run the **Create Rejected Submission Release** and **Create Accepted Submission Release**

For other setups, contact OpenReview Support by adding a comment to your [venue request form](../../getting-started/hosting-a-venue-on-openreview/navigating-your-venue-pages.md#venue-request-form).
