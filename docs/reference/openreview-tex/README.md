# OpenReview TeX

OpenReview renders TeX and LaTeX notation with the open source library [MathJax](https://docs.mathjax.org/en/latest/index.html). It is available in forum comments and reviews, paper abstracts, and venue homepages. Use `$...$` for inline math and `$$...$$` for displayed math.

* [OpenReview TeX support](openreview-tex-support.md) describes what MathJax supports, what it restricts, and how TeX interacts with Markdown and with the surrounding HTML.
* [Common Issues with LaTeX Code Display](common-issues-with-latex-code-display.md) covers what to check when your notation does not render the way you expect.

For an example of writing formulas in a submission or a review, see [How to add formulas or use mathematical notation](../../how-to-guides/submissions-comments-reviews-and-decisions/how-to-add-formulas-or-use-mathematical-notation.md).
